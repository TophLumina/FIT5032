TTFB reduction:

* **Use a CDN and caching.** Serving content from a server closer to the visitor can reduce waiting time. Our site already uses Cloudflare Pages, which provides built-in caching. [Cloudflare: Caching and performance](https://developers.cloudflare.com/pages/configuration/serving-pages/#caching-and-performance)
* **Avoid unnecessary redirects.** Each redirect adds another request before the browser reaches the page. Linking directly to the final HTTPS address keeps things quicker. [web.dev: Optimize TTFB](https://web.dev/articles/optimize-ttfb)
* **Keep backend processing fast.** If the site later uses a backend, we can improve database queries, cache reusable results, and reduce external API calls that delay the response. [web.dev: Optimize TTFB](https://web.dev/articles/optimize-ttfb)

Hotlink avoid：

* **Enable Cloudflare Hotlink Protection.** For a custom domain managed through Cloudflare, this is a straightforward option. It checks the referring website and protects common image formats, including JPG, PNG, GIF and ICO. Requests without a `Referer` are still allowed. [Cloudflare: Hotlink Protection](https://developers.cloudflare.com/waf/tools/scrape-shield/hotlink-protection/)
* **Add a CORP response header.** Setting `Cross-Origin-Resource-Policy: same-origin` tells browsers to restrict cross-origin embedding. On Pages, we can configure this in `_headers` and remove permissive CORS headers from protected resources. This is browser-side protection, so it does not stop people downloading the files. [MDN: CORP](https://developer.mozilla.org/en-US/docs/Web/Security/Practical_implementation_guides/CORP), [Cloudflare: Custom headers](https://developers.cloudflare.com/pages/configuration/headers/)
* **Check requests with a Function or Worker.** We can check the `Referer` and return **403 Forbidden** for requests from other websites. This gives us more control, but it is not foolproof because the header can be missing or forged. [Cloudflare: Hotlink protection example](https://developers.cloudflare.com/workers/examples/hot-link-protection/)
